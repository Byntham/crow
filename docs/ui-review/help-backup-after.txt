$ crow backup --help

Save an encrypted backup of this installation

Usage: crow backup [OPTIONS] --passphrase-file <PASSPHRASE_FILE> <FILE>

Arguments:
  <FILE>
          Destination archive path

Options:
      --passphrase-file <PASSPHRASE_FILE>
          File containing the encryption passphrase

      --format <FORMAT>
          Result format; JSON is available for noninteractive commands

          Possible values:
          - text: Readable summaries and tables
          - json: Structured command results for scripts
          
          [default: text]

  -h, --help
          Print help (see a summary with '-h')
