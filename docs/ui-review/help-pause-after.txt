$ crow pause --help

Pause a review and keep its saved work

Usage: crow pause [OPTIONS] <REPO> <NUMBER>

Arguments:
  <REPO>
          Repository in OWNER/REPO format

  <NUMBER>
          Pull request number, for example 42

Options:
      --format <FORMAT>
          Result format; JSON is available for noninteractive commands

          Possible values:
          - text: Readable summaries and tables
          - json: Structured command results for scripts
          
          [default: text]

  -h, --help
          Print help (see a summary with '-h')

Example: crow pause owner/repo 42
Continue later with crow resume owner/repo 42.
