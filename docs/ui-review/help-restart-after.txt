$ crow restart --help

Start a fresh review, replacing the previous attempt

Usage: crow restart [OPTIONS] <REPO> <NUMBER>

Arguments:
  <REPO>
          Repository in OWNER/REPO format

  <NUMBER>
          Pull request number, for example 42

Options:
      --format <FORMAT>
          Result format; JSON is available for noninteractive commands

          Possible values:
          - text: Readable summaries and tables
          - json: Structured command results for scripts
          
          [default: text]

  -h, --help
          Print help (see a summary with '-h')

Example: crow restart owner/repo 42
