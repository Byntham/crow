$ crow start --help

Start Crow in the background

Usage: crow start [OPTIONS]

Options:
      --format <FORMAT>
          Result format; JSON is available for noninteractive commands

          Possible values:
          - text: Readable summaries and tables
          - json: Structured command results for scripts
          
          [default: text]

  -h, --help
          Print help (see a summary with '-h')
