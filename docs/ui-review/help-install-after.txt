$ crow install --help

Install Crow on this machine and start setup

Usage: crow install [OPTIONS]

Options:
      --no-setup
          Install without opening the setup wizard

      --format <FORMAT>
          Result format; JSON is available for noninteractive commands

          Possible values:
          - text: Readable summaries and tables
          - json: Structured command results for scripts
          
          [default: text]

  -h, --help
          Print help (see a summary with '-h')
