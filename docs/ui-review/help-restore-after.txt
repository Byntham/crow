$ crow restore --help

Restore a backup, replacing settings and history on this machine

Usage: crow restore [OPTIONS] --passphrase-file <PASSPHRASE_FILE> <FILE>

Arguments:
  <FILE>
          Backup archive to restore

Options:
      --passphrase-file <PASSPHRASE_FILE>
          File containing the backup's encryption passphrase

      --format <FORMAT>
          Result format; JSON is available for noninteractive commands

          Possible values:
          - text: Readable summaries and tables
          - json: Structured command results for scripts
          
          [default: text]

  -h, --help
          Print help (see a summary with '-h')

Stop Crow before restoring with crow stop. Existing settings and review history are replaced.
After restoring, run crow login on review workers, then crow start.
